## ✨ Why Practice with NextScore?

- 🎹 **[Interactive Sheet Music Library](https://nextscore.org/)** — Instant browser playback with Acoustic Grand Piano SoundFont, zero install required.
- 🌊 **[60fps Synthesia-Style Waterfall Visualizer](https://nextscore.org/studio/?play=1)** — Dual-hand color coding, adjustable tempo, loop measures, and **Do-Re-Mi (Đô-Rê-Mi) / Letter (C-D-E)** labels.
- 📡 **Wireless Bluetooth BLE-MIDI & USB MIDI Sync** — Connect Yamaha, Roland, Casio, Kawai, Korg, or ESP32 BLE pianos directly in Chrome/Edge via Web Bluetooth (`Wait-for-Key` pauses until you play the right notes!).
- 📥 **100% Open Formats (CORS: `*`)** — Every public score provides direct **Vector SVG**, **Standard MIDI (`.mid`)**, and **W3C MusicXML 4.0 (`.musicxml`)** downloads.
- 🤖 **AI & Developer Friendly** — Structured metadata in [catalog/scores_seo_catalog.json](./catalog/scores_seo_catalog.json) and [llms.txt](https://nextscore.org/llms.txt).
